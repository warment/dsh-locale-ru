Русский языковой пакет для веб-интерфейса DeepSeek Harness. Официальный интерфейс поставляется только с английским и китайским языками, а этот плагин добавляет «Русский» в штатный переключатель языка. Пакет оформлен как плагин (bundle) dsh и использует документированный API внешних плагинов для локали — файлы самого Harness не модифицируются.

## Установка

```bash
# из реестра плагинов
dsh plugin --profile web add dsh-locale-ru

# напрямую из GitHub-репозитория
dsh plugin --profile web add github:warment/dsh-locale-ru

# из локальной копии репозитория
dsh plugin --profile web add /path/to/dsh-locale-ru
```

Первые два способа заработают после публикации пакета и репозитория. После установки перезапустите `dsh web`.

## Как переключить язык

Откройте **Settings → General** и выберите **«Русский»** в списке языков — пункт появляется там после установки плагина и перезапуска `dsh web`.

Если какой-то строки в словаре пока нет, она отображается на английском: английский задан резервным языком.

## Обновление и удаление

Чтобы обновиться до новой версии, удалите пакет и установите заново:

```bash
dsh plugin --profile web remove dsh-locale-ru
dsh plugin --profile web add dsh-locale-ru
```

Удаление:

```bash
dsh plugin --profile web remove dsh-locale-ru
```

После любых изменений состава плагинов перезапустите `dsh web`.

## Участие в переводе

Будем рады правкам. Переводы лежат в `dict/ru/<namespace>.json` — по одному файлу на пространство имён; английские исходные строки — в `upstream/corpus.json`. Порядок работы:

1. Отредактируйте нужный файл в `dict/ru/`.
2. Проверьте словари:

   ```bash
   node scripts/check.mjs
   ```

3. Пересоберите клиентскую часть:

   ```bash
   node scripts/build.mjs
   ```

4. Закоммитьте оба изменения: файл словаря и обновлённый `lib/client.js`.

Подробные правила оформления переводов — в [CONTRIBUTING.md](CONTRIBUTING.md). Инструкция для мейнтейнеров по обновлению словаря после релизов upstream — в [docs/upstream-sync.md](docs/upstream-sync.md).

## Совместимость

Плагин ориентируется на актуальные релизы [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness). Когда в upstream появляются новые строки интерфейса, полноту словаря показывает `node scripts/check.mjs` — он печатает таблицу покрытия по пространствам имён. Неполный перевод интерфейс не ломает: недостающие строки отображаются на английском.

## Состав репозитория

- `dict/ru/*.json` — исходники перевода, один файл на пространство имён;
- `upstream/corpus.json` — английские строки, извлечённые из upstream;
- `lib/client.js` — собранная клиентская часть (генерируется `node scripts/build.mjs` и коммитится, поэтому сборка пользователям не нужна);
- `scripts/` — проверка (`check.mjs`), сборка (`build.mjs`), извлечение строк из upstream (`extract.mjs`), живая проверка загрузки (`verify-boot.mjs`).
